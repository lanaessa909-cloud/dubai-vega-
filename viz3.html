2. Encoding

  • View 1 – heatmap: x-axis = transaction group (Sales, Mortgages, Gifts); y-axis = property type (Unit, Villa, Land, Building). Each rectangle represents one combination. The colour intensity and the number printed inside each rectangle encode the count of transactions. A square-root colour scale keeps smaller groups readable. The selected cell has an orange outline.
  • View 2 – linked bar chart: x-axis = registration type (Existing Properties vs Off-Plan Properties); y-axis = number of transactions. The bars are coloured by registration status (blue = existing, orange = off-plan), and labels show both the count and the percentage of the current selection. All three views use the same room-category filter.
  • View 3 – yearly trend: x-axis = year (2015–2026); y-axis = number of transactions; line colour = existing (blue) versus off-plan (orange). The linked line chart shows how the selected transaction/property combination changed over time. Hover reveals yearly counts and the share within each year.

3. Interaction

  • Dropdown: select a room category, or “No room data”, to filter all three views.
  • Hover: see counts in the heatmap, count and percentage in the bars, and annual counts and shares in the trend.
  • Click: select a heatmap cell (e.g., Sales + Unit) to update both the bar chart and the yearly line chart to that combination.
  • Double-click: reset the heatmap selection so the two lower charts show all transaction/property groups (still respecting the room filter).

4. Value added

In the team's cleaned date window (67,022 sampled transactions), the chart reveals concrete differences in market structure:

  • Units dominate sales: Sales + Unit accounts for 39,809 transactions (59.4% of all 67,022).
  • Off-plan is stronger for units: 62.2% of unit sales are off-plan, compared with 47.2% of villa sales.
  • Mortgages mostly involve existing properties: 98.6% of mortgage transactions are existing-property registrations. The data does not tell us how every off-plan purchase was financed.
  • Villas have more mortgage registrations proportionally: mortgages account for 34.4% of all villa transactions versus 14.1% of all unit transactions.
  • Gifted units are mostly existing: 91.9% of unit gift transactions refer to existing properties (not 92% of all gifts).
  • Time adds a new insight: in unit sales, off-plan transactions overtook existing sales again in 2022 and the gap expanded through 2025 (6,230 off-plan vs 2,496 existing in 2025). Select Sales + Unit to see this pattern. This view reveals when market structure changed, not only which category is largest.

Why it helps: buyers and investors can compare market segments and registration status, while planners can see which transaction types are growing. The linked filters prevent mixing unlike property and room categories.

Data quality and limitations

  • Applies the team's shared date window: 1 January 2015–31 August 2026, with invalid dates excluded.
  • Uses all transaction groups and property types for count analysis. The sales-price trimming rule is deliberately not applied, because no prices are encoded in these charts.
  • Missing room values remain in the “All” view; choosing “No room data” shows only those missing entries. This is common by design for land and buildings, so missing rooms does not mean the entire row is unusable.
  • The data is a random 10% sample, so counts show sampled transactions rather than total Dubai volumes. Counts refer to transactions, not unique properties. The 2026 yearly total is incomplete (January–August).
